# T5 scheduler dispatch adequacy review

Scope: typed Draft/Rule actions, isolated game dispatcher, durable admission/notification/result ordering, completion cadence and owned shutdown. Minimal app compatibility bridge is mapped separately in t5-bridge.md. No gameplay request was sent to the real game for these tests; all execution transports are synthetic.

Red evidence: t5-api-red.log and t5-red.log capture pre-implementation generic API/dispatch failures. t5-behavior-red.log captures missing dispatch behavior. Parent review identified a concrete shutdown race: an independent discovery queued on GameActionsService could start while coordinator persisted/drained the active result. t5-dispose-race-red.log proves discoveryStarted before the fix; t5-dispose-race-green.log proves serviceUnavailable with one factory and closed active transport after immediate executor disposal.

Final Quick gate: t5-green.log, 405 tests passed, exit 0 (T4 baseline383 plus22 meaningful tests). t5-analyze.log, flutter analyze packages/popmundo_utils, no issues, exit 0. App bridge Full gate: t5-bridge-green.log,165 tests passed, exit0; t5-bridge-analyze.log, no issues, exit0. Existing local assertion values and coverage retained; only known LocalNotificationAction casts added to accommodate the sealed base type.
